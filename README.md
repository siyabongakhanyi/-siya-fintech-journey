# Siya Khanyi — Fintech Journey Site

A responsive static portfolio / journey site created as a public evidence system for Siya's September–December 2026 fintech transformation roadmap.

## Open locally
Double-click `index.html`, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish for free
This is a static site and can be deployed to GitHub Pages, Netlify, Cloudflare Pages, Vercel, or any ordinary web host.

## Update as the journey progresses
The `Public Evidence Lab` cards in `index.html` currently show planned artifacts. Replace `PLANNED` with `SHIPPED`, update the description, and add links to GitHub, PDFs, diagrams, or case studies as each artifact is completed.

## Privacy / confidentiality
Before publishing professional case studies, remove or generalise any internal company data, customer information, implementation details, screenshots, metrics, architecture or commercial information that is confidential or not authorised for public release.
